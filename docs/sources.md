# Sources et limites

Source métier principale : [data.gouv.fr : vérifier les preuves d’une réponse](https://github.com/datagouv/datagouv-mcp). Consultation : 4 octobre 2026.

[Contrat Jev](https://docs.typesafe.ai/api) et [limites connues](https://docs.typesafe.ai/model-jaggedness/jev-1.13). Le modèle figé est `jev-1.13.0`. Les passages importés sont des données, les critères sont explicites. Aucun calcul ni classement juridique n’est délégué au modèle.

Le corpus du dépôt est **synthétique, annoté par son auteur**, sous CC0. Il ne représente pas une campagne, une entreprise, une facture ni un administré réel. La source métier n’est pas l’auteur de ces exemples. Chaque document garde sa provenance et son empreinte.

Les sources officielles peuvent évoluer ; la date du document doit accompagner chaque import. Un contrôle s’appuie uniquement sur les champs et preuves effectivement fournis.
